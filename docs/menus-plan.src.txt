# Anne's Base classic menu layouts — source file, read by scripts/gen-plan.py.
# Every entry is a command id from commands-plan.src.txt; the generator fails if an id is unknown.
#
#   @layout <key> | <menu-bar name in View ▸ Classic Menu Layout> | <modeled on>
#   = <Menu>                 starts a top-level menu
#   > <Submenu>  …  <        a submenu (one level)
#   ---                      separator
#   <command id>
#
# The "AI" menu is the same in every layout and is appended before Help (or at the end) by the generator.
# "All programs combined" is generated: the union of the layouts below, menu by menu, without duplicates.
# Programs whose menus change with the object or mode (Access 2003's Format, Records and Query menus,
# FileMaker's Records menu) are shown with every contextual menu present; the app shows each in its context.
