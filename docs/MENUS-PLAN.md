# Classic menu layouts (plan)

> **Plan.** Generated by `scripts/gen-plan.py` from [menus-plan.src.txt](menus-plan.src.txt). Every entry is a command id from [COMMANDS-PLAN.md](COMMANDS-PLAN.md); the generator fails if a layout names a command that does not exist, the same check `tests/unit/catalog.test.ts` will make once there is code.

Anne's Base has two menu systems over one command library, as Anne's Loom and Anne's Lens do:

- **The suite ribbon** (File, Home, Create, External Data, Database Tools, Data, Repair & Recovery, xBase, View, AI, Developer, Help, plus the contextual Table, Query, Form and Macro tabs), with the Quick Access Bar, command search (Alt+Q), Customize Ribbon and Customize Keyboard. The ribbon is the default, as in Access 2007 and later.
- **A classic menu bar** laid out like the database programs people learned. *View ▸ Menus* switches between ribbon, menu bar or both; *View ▸ Classic Menu Layout* (`view.menuLayout`) picks the program whose layout the bar follows. **Access 2003 style is the default** for the menu bar. *View ▸ Customize Menus* edits any layout or builds a new one.

A command found in the dBASE-style *Organize* menu is the same command as on the ribbon: it can go on the Quick Access Bar, gets a shortcut and records in macros. *Help ▸ Menu Map* (`help.menuMap`) shows where a command lives in every layout. Each layout reproduces the *arrangement* of commands people know, under Anne's Base's own labels; it is not a copy of any program's menu text (see [LEGAL.md](LEGAL.md)). The arrangements were compiled from product knowledge and documentation and will be checked against installed copies or published manuals before implementation (tracked in [ROADMAP.md](ROADMAP.md), M0). Programs whose menus change with the object or mode (Access 2003's Format, Records and Query menus, FileMaker's Records menu) are listed with every contextual menu; the app shows each in its context.

The **AI** menu is the same in every layout and sits just before Help.

## Ribbon

The default ribbon shows each tab's groups in the order of COMMANDS-PLAN.md. Two tabs gather commands from other tabs:

**Home** (the default tab):

| Group | Commands |
|---|---|
| Views | View (`view.objectView`), Datasheet View (`view.datasheet`), Form View (`view.form`), Design View (`view.design`) |
| Clipboard | Paste (`edit.paste`), Cut (`edit.cut`), Copy (`edit.copy`), Format Painter (`edit.formatPainter`) |
| Sort & Filter | Sort Ascending (`sort.ascending`), Sort Descending (`sort.descending`), Filter (`filter.menu`), Selection (`filter.bySelection`), Filter by Form (`filter.byForm`), Apply/Toggle Filter (`filter.toggle`), Natural-Language Filter… (`filter.natural`) |
| Records | New Record (`record.new`), Save Record (`record.save`), Delete Record (`record.delete`), Refresh All (`record.refreshAll`), Totals Row (`record.totals`), Spelling (`record.spelling`), More (`record.more`) |
| Find | Find… (`edit.find`), Replace… (`edit.replace`), Go To (`edit.goTo`), Select (`edit.select`) |
| Ask | Ask Your Data… (`ai.ask`) |

The **Home** tab gathers the everyday commands from other tabs, as in Access. The contextual **Table**, **Query**, **Form** and **Macro** tabs appear with their designers, as Access's Table Tools, Query Tools, Form Design Tools and Macro Tools do.
