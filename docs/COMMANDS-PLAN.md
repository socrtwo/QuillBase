# Command inventory plan

> **Plan.** Anne's Base has no code yet. This is the planned command inventory: every command of Microsoft Access and of the major database programs past and present, tab by tab, with the command id Anne's Base will use and where the idea comes from, plus commands that are new in Anne's Base. It is generated by `scripts/gen-plan.py` from [commands-plan.src.txt](commands-plan.src.txt); edit that file, not this one. When the app exists, `npm run catalog` will generate `docs/COMMANDS.md` from the command registry, and this plan will be retired.

**693 commands** in 16 tabs (129 of them new ideas). Every command will be usable on the Quick Access Bar, on custom tabs, in every classic menu layout ([MENUS-PLAN.md](MENUS-PLAN.md)), on a keyboard shortcut, in a macro and in command search (Alt+Q). Commands marked *not in tabs* have no default place on a tab but are reachable everywhere else, so nothing is hidden.

## Conventions

- **ids** are `area.name` in camelCase, as in the other Anne's Office apps. Where a sister app already defines a command (`file.save`, `edit.undo`, `view.cmdSearch`, `view.qatAddAll`, `ai.setup`…), Anne's Base reuses the id so shared settings, macros and Quick Access Bar layouts carry over.
- **Arguments.** Some commands take an argument, written `id(arg)` in macros and layouts (`view.menuLayout(dbase4)`, `query.dialect(postgresql)`); the notes list the arguments.
- **Shortcuts** are planned defaults and follow Microsoft Access where its keys are well known (F11 navigation pane, F5 go to record, F9 refresh, Shift+F9 requery, Ctrl+; date, Ctrl+' value from previous record, Shift+Enter save record, F4 property sheet, F8 field list, Alt+F11 code editor, Ctrl+G Immediate window). All can be rebound; Customize Keyboard also loads FileMaker, FoxPro and SQL Server Management Studio key sets. The generator rejects duplicate defaults.
- **Origin** says where the command or idea comes from (nominative use; see [LEGAL.md](LEGAL.md)). **new** marks ideas not found in the programs surveyed (they may exist in other software); *suite* marks commands shared with the sister apps.
- **Vendor feature names** are replaced with generic terms (Ask Your Data, Locked Application, Card Stack…).
